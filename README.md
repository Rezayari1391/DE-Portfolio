# DevPortfolio - Modern Open-Source Developer Portfolio

DevPortfolio is a fast, lightweight, and visually stunning developer portfolio template engineered with zero external framework dependencies (Pure HTML5, CSS3, and Vanilla JavaScript).

## 🌟 Key Features
- **Config-Driven Architecture**: Easily update content via `config/portfolio.js` without editing HTML.
- **Dark-First Modern UI**: Glassmorphic styling, emerald glowing accents, and smooth animations.
- **Dependency-Free**: Lightweight runtime with zero build steps or npm scripts required.
- **Web3Forms Integration**: Fully functional contact form with client-side validation and asynchronous fetch submission.
- **Responsive & Accessible**: Optimized for mobile, tablet, desktop, keyboard navigation, and reduced motion settings.
