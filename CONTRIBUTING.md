# Contributing to DevPortfolio

Thank you for taking the time to contribute to DevPortfolio!

## How to Contribute
1. Fork the Repository.
2. Create your Feature Branch (`git checkout -b feature/AmazingFeature`).
3. Commit your Changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the Branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.

## Guidelines
- Follow semantic HTML5 standards.
- Maintain pure Vanilla JS code style without introducing framework dependencies.
- Ensure all components remain responsive and accessible.
